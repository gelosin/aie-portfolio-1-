# AI Engineering Student Portfolio

A modern, responsive, and minimalist personal portfolio website built with HTML5, CSS3, and vanilla JavaScript, designed specifically to showcase academic projects and learning reflections for an Artificial Intelligence Engineering student.

## 📁 File Structure
- `index.html` — Main website containing all 5 required sections (Home, About, Portfolio, Reflections, Contact).
- `style.css` — Visual styling, responsive grid layouts, and theme variables for dark/light mode.
- `script.js` — Interactive behaviors including mobile navigation, theme switcher, and scroll tracking.
- `assets/` — Folder for storing your profile image (`profile.jpg`) and project screenshots.

## 🖼️ Replacing Placeholders & Images
1. **Profile Photo**: Replace `assets/profile.jpg` with your own professional photo (recommended dimensions: square or portrait 4:5 ratio).
2. **Project Images**: Replace `assets/project1.jpg` with screenshots or diagrams of your lab outputs and projects.
3. **Text Placeholders**: Open `index.html` in any code editor (like VS Code) and search for bracketed text placeholders such as `[INSERT YOUR NAME]`, `[Write your background here]`, and update them with your actual content.

## 🚀 Adding New Projects or Reflections
- **To add a project**: Copy an existing `<article class="project-card">...</article>` block inside `index.html`'s `#projectGrid` and update its title, tech tags, and description.
- **To add a reflection**: Copy an existing `<article class="reflection-card">...</article>` block inside `#reflectionsFeed` and write your entry.
